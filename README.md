🚀 Perplexity.social
Empowering Influencers with Personalized Web Experiences



🌐 Live Website: https://perplexity.social

📌 Overview

Perplexity.social is a personalized web platform for influencers, built with a frontend-first approach.
It helps creators grow, collaborate, and make data-driven decisions by combining clean UI design with machine learning insights.


🎯 Project Goal

The primary goal of this project is to:

Empower influencers through personalized websites

Provide insights for content growth and planning

Predict YouTube video views using ML

Enable collaboration between creators



📄 Pages

index.html – Home: hero, services overview, process, AI predictor preview, demos, testimonials

about.html – Our story, mission & vision, values, founder profile, journey and tech stack

services.html – Detailed services, process, pricing plans and FAQ

work.html – Featured case study and filterable project portfolio

ai-predictor.html – How the Random Forest + XGBoost views predictor works

contact.html – Contact options and collaboration form (Formspree)



🛠️ Tech Stack
🎨 Frontend Technologies

HTML – Semantic structure and SEO-friendly markup

CSS – Design tokens, responsive layout, animations (assets/css/style.css)

JavaScript – Mobile nav, scroll reveal, counters, project filters, contact form and chatbot (assets/js/script.js)

Google Fonts (Plus Jakarta Sans) and Font Awesome icons via CDN



🧠 Machine Learning

Ensemble Learning Approach

Random Forest

XGBoost

Used to predict YouTube video views based on historical data



🧩 Personalization & Intelligence

Each influencer receives a personalized web presence, allowing them to showcase their profile and growth metrics.
The integrated ML model helps creators estimate video performance before publishing, enabling smarter content strategies.


✨ Key Features

Personalized influencer websites

YouTube view prediction using ML

PerplexityBot chatbot on every page

Data-driven insights for growth

Designed to support collaboration
